# SL Cleaning Services

Website for **SL Cleaning Services** — professional residential and commercial cleaning across **Los Angeles County** and **Orange County**.

**Website:** [https://slcleaningservices.online](https://slcleaningservices.online)

---

## About

- Service pages (residential, deep cleaning, move-in/move-out, commercial)
- Service areas across LA & Orange County
- Online quote request
- English / Spanish
- Light and dark mode

---

## Tech stack

- [Vite](https://vitejs.dev/) + [React](https://react.dev/)
- [React Router](https://reactrouter.com/)
- Hosted on [Vercel](https://vercel.com/)

---

## Local development

```bash
npm install
npm run dev
```

```bash
npm run build    # production build
npm run preview  # preview the build
```

---

## Project layout

```
src/           # React app (pages, components, styles)
public/        # Static assets
api/           # Serverless API routes (Vercel)
```
